# Aplicación Interactiva Unity

Proyecto de la unidad 2 enfocado en la creación de una escena adaptable a diferentes tamaños de pantalla.

## Elementos incluidos

- Escena principal
- Canvas responsivo
- Tres botones de navegación
- Puntos de anclaje
- Adaptación a diferentes resoluciones
